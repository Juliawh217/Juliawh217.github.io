Interactive Visualization Report

1. Problem

This project aims to explore the relationship between a country's GDP and its population. By visualizing these two variables, users can investigate whether larger populations are associated with higher economic output and identify patterns among countries.

2. Design Decisions

Visualization Type

A scatter plot was chosen because it effectively represents the relationship between two quantitative variables (GDP and population).

Visual Encoding

  • X-axis: GDP
  • Y-axis: Population
  • Points: Countries
  • Color: Highlight on hover
  • Opacity: Improve readability when points overlap

Interaction Design

  • Zoom & Pan: Users can drag and scroll to explore different regions.
  • Hover Highlight: Points are highlighted when hovered.
  • Tooltip: Displays country name, GDP, and population.

Alternative Designs

Other options such as bar charts and line charts were considered but rejected due to their limitations in representing relationships between two continuous variables.

3. Data Source

Data is obtained from the World Bank (World Development Indicators):

  • GDP (NY.GDP.MKTP.CD)
  • Population (SP.POP.TOTL)

The dataset was cleaned to remove aggregate entries such as "World" and "High income".

4. Development Process

The project was developed through the following steps:

  1. Data collection from World Bank
  2. Data cleaning and merging
  3. Building the scatter plot
  4. Adding interactive features
  5. Improving visual design and layout
  6. Deploying using GitHub Pages

Total time spent: approximately 10 hours

Most time-consuming parts: data cleaning and debugging Vega-Lite configurations.

5. Conclusion

This project demonstrates how interactive visualization can support exploratory data analysis. The design focuses on simplicity, clarity, and usability, allowing users to effectively explore global economic patterns.
